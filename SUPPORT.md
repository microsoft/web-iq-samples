# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/web-iq-samples/issues)
for questions, bug reports, and feature requests about these samples. Please
search existing issues before opening a new one.

For a bug report, include the sample name, setup and run commands, expected and
actual behavior, and relevant software versions. Remove credentials, personal
data, and other sensitive information from logs and reproduction steps.

Do not report security vulnerabilities through GitHub Issues. Follow the
reporting instructions in [SECURITY.md](SECURITY.md).

## Microsoft Support Policy

Support for these samples is limited to the resources listed above.
