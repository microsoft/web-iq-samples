# Web IQ Samples

Runnable examples for building applications with Microsoft Web IQ.

## Project status

This repository includes the runnable Market briefing sample listed below,
alongside documentation and repository configuration. No third-party source code
is vendored; the sample installs its dependencies separately.

## Samples

Samples are organized by implementation language or infrastructure technology:

```text
samples/
  <language-or-technology>/
    <sample-name>/
```

Each sample is self-contained and includes its own prerequisites, configuration,
run instructions, and validation steps.

| Sample | Language | Description |
|---|---|---|
| [Market briefing](samples/python/market-briefing/) | Python | Uses Web IQ web and news passages and Azure OpenAI to generate a cited Markdown briefing. Supports API-key or certificate-based Microsoft Entra authentication for Web IQ. |
